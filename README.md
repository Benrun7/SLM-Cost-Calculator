# SLM Cost Calculator

Веб-калькулятор для быстрой оценки стоимости запуска SLM-печати. Сервис помогает посчитать порошок, газ, ресурс фильтра, обработку платформы, ФОТ и срок проекта по геометрии компоновки.

## Что считает

Калькулятор поддерживает два сценария:

- **Быстрый ручной расчёт**: пользователь вводит объём деталей, объём поддержек и высоту запуска. Среднее сечение можно оставить `0`, тогда оно считается как `(объём деталей + объём поддержек) / высота`.
- **Расчёт из Magics CSV**: сервис импортирует таблицу срезов Magics и рассчитывает объём деталей, объём поддержек, среднее сечение, высоту запуска и высоту слоя.

Поддержки считаются частью сплавляемого объёма: они влияют на время печати, массу сплавленного металла и списываемый порошок. Масса годных деталей показывается отдельно.

## Методика порошка

В расчёте разделены две величины:

- **Списываемый порошок**: масса деталей + масса поддержек + резерв порошка. Именно эта масса используется для стоимости порошка.
- **Требуется порошка в камере**: сплавленный металл + несплавленный порошок в рабочем объёме камеры. Это справочная технологическая величина, а не прямое списание в себестоимость.

Такой подход позволяет оперативно считать компоновки без тяжёлого STL с поддержками и не завышать стоимость за счёт полной засыпки камеры.

## Основные входные параметры

- объём деталей, мм3;
- объём поддержек, мм3;
- высота запуска, мм;
- высота слоя, мм;
- количество лазеров;
- скорость и шаг штриховки;
- скорость контуров;
- время нанесения слоя;
- плотности и стоимость порошка;
- резерв списываемого порошка;
- трудозатраты и ставки команды.

## Импорт файлов

Поддерживаются:

- `.stl` для оценки объёма и высоты деталей без технологических поддержек;
- `.csv` / `.txt` из Magics с таблицей распределения срезов;
- простые CSV с колонками `partsVolumeMm3`, `supportVolumeMm3`, `meanSectionMm2`, `buildHeightMm`, `estimatedLayerTimeSec`.

Прямой импорт `.xlsx` пока не реализован. Excel-файлы в `test/` используются как контрольные материалы для сверки методики.

## Запуск

```bash
npm install
npm run dev
```

По умолчанию Vite поднимает приложение на `http://localhost:5173/`.

```bash
npm run build
npm run lint
```
